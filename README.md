
# Software Testing Projects

Hi, I'm Poojitha Bathala — a Computer Science graduate with hands-on practice in Manual Testing and Automation Testing.

This repository contains my testing projects, including manual test cases, defect reports, and Selenium automation scripts. I have worked on real-world demo applications and practised different testing scenarios.

## Projects

### 1. Gmail – Manual Testing

Tested Gmail's main email functionalities.

- **Modules tested:** Compose & Send, Scheduling, Inbox, Compose Window, Snooze
- **Test cases:** 18, covering functional, negative, and boundary scenarios
- **Highlights:** Recipient handling (To/CC/BCC), schedule and snooze time validation, and confirmation-dialog behaviour
- **File:** `Gmail_Manual_Testing.xlsx`

### 2. E-Commerce Website – Manual Testing (OpenCart)

Tested the public demo website [demo.opencart.com](https://demo.opencart.com/), covering the main e-commerce user journey.

- **Modules tested:** Registration, Profile Management, Search, Cart, Checkout & Payment
- **Test cases:** 25, covering positive, negative, and boundary scenarios
- **Defects found:** 2, documented with severity, priority, and steps to reproduce
- **File:** `opencart_Ecommerce_Testing.xlsx`

### 3. SkillGun – Student Training & Placement Portal (Manual Testing)

Performed self-driven manual testing of the SkillGun portal, covering 14 modules.

- **Modules tested:** Login, Profile Settings, Refer a Friend, Placement Drive, Interview Schedule, Attendance Report, and other portal modules
- **Test cases:** 28, designed and executed in Excel, covering positive and negative scenarios
- **Testing coverage:** Pre-conditions, post-conditions, and expected vs. actual results
- **Highlights:** Validated login with invalid password and CAPTCHA combinations, password change, contact-detail updates, and resume upload
- **Defects found:** 1 defect in the Refer a Friend module, documented with severity and priority
- **File:** `Skillgun_project.xlsx`

### 4. Skillgun – Automation Testing (POM Framework)

Developed an automation testing project using Python and Selenium WebDriver, following the Page Object Model (POM) design pattern.

- **Framework:** Page Object Model (POM)
- **Tools used:** Python, Selenium WebDriver, Pytest
- **Test cases:** 16
- **Project folder:** `Automation_project_POM/`

## Test Case Format

Manual testing test cases include Test ID, Description, Steps, Test Data, Pre-condition, Expected Result, Actual Result, Post-condition, Status, Priority, Severity, and Bug ID (where applicable).
