# Manual Testing Projects

Hi, I'm Poojitha Bathala — a Computer Science graduate currently building hands-on 
experience in Manual Testing, with automation testing as my next step.

This repository contains self-driven manual testing practice on two real-world 
applications, documented the way I would on a professional QA team: structured 
test cases, clear pass/fail status, and formal defect reports for bugs found.

## Projects

### 1. Gmail — Manual Testing
Independent testing of Gmail's core email workflows.
- **Modules tested:** Compose & Send, Scheduling, Inbox, Compose Window, Snooze
- **Test cases:** 18, covering functional, negative, and boundary scenarios
- **Highlights:** Recipient handling (To/CC/BCC), schedule/snooze time validation 
  (rejecting past date-times), and confirmation-dialog behavior for blank subject/body
- File: `Gmail_Manual_Testing.xlsx`

### 2. E-Commerce Website Testing (OpenCart Demo)
Manual testing of [demo.opencart.com](https://demo.opencart.com), a public e-commerce 
demo site, covering the full user journey from registration to checkout.
- **Modules tested:** Registration, Profile Management, Search, Cart, Checkout & Payment
- **Test cases:** 25, covering positive, negative, and boundary scenarios
- **Defects found:** 2, documented with severity, priority, and steps to reproduce
- File: `OpenCart_Ecommerce_Testing.xlsx` (includes a separate Defect Report sheet)

## Test Case Format
Each sheet includes: Test ID, Description, Steps, Test Data, Pre-condition, 
Expected Result, Actual Result, Post-condition, Status, Priority, Severity, and 
Bug ID (where applicable).
