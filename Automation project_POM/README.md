# Automation Testing Project – POM Framework

## Project Overview
This project is an automation testing framework developed using Python and Selenium WebDriver, following the Page Object Model (POM) design pattern.

The project contains 16 test cases covering different functionalities of the application.

## Technologies Used
- Python
- Selenium WebDriver
- Pytest
